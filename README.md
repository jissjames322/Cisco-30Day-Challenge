# \# 30 Days of Cybersecurity

# 

# My hands-on cybersecurity learning journey based on Cisco's Cybersecurity Awareness Month 30-Day Challenge.

# 

# The goal is to strengthen my practical knowledge of cybersecurity, network defense, security operations, threat detection, incident response, and ethical hacking while documenting everything in an organized, version-controlled knowledge base.

# 

# \## Objectives

# 

# \- Strengthen security fundamentals and the CIA triad.

# \- Understand common threats, malware, phishing, and authentication security.

# \- Practice network segmentation, access control, firewall rules, and endpoint defense.

# \- Learn SIEM fundamentals, security monitoring, log analysis, and detection engineering.

# \- Explore Splunk, SPL, SOAR, and incident response workflows.

# \- Perform authorized vulnerability assessments in lab environments.

# \- Explore cloud security, Zero Trust, and AI-assisted security.

# \- Complete a cybersecurity capstone and document the investigation process.

#

# \## Daily Workflow

# 

# For each challenge, I will:

# 

# 1\. Learn the concept using the recommended resources.

# 2\. Complete the assigned activity or authorized hands-on lab.

# 3\. Document the methodology, commands, observations, and results.

# 4\. Record key takeaways and areas for improvement.

# 5\. Update my progress tracker and commit the notes to GitHub.

# 

# \## Knowledge Base

# 

# My notes are maintained in Markdown using Obsidian and version-controlled with Git.

# 

# The repository includes daily learning notes, lab documentation, investigation findings, useful commands, references, and a final capstone report.

# 

# \## Responsible Security Practice

# 

# All scanning, testing, and exploitation activities are restricted to systems I own or have explicit authorization to assess. Sensitive credentials, personal information, and confidential infrastructure details are excluded from this repository.
