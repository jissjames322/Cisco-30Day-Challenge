# 30 Days of Cybersecurity

  

A hands-on cybersecurity learning journey based on Cisco's **Cybersecurity Awareness Month — 30-Day Challenge**.

  

The goal is to strengthen practical knowledge of cybersecurity, network defense, security operations, threat detection, incident response, and ethical hacking while documenting progress in an organized, version-controlled knowledge base.

  

## Objectives

  

- Strengthen security fundamentals, including the CIA triad.

- Understand common threats, malware, phishing, and authentication security.

- Practice network segmentation, access control, firewall rules, and endpoint defense.

- Learn SIEM fundamentals, security monitoring, log analysis, and detection engineering.

- Explore Splunk, Search Processing Language (SPL), SOAR, and incident response workflows.

- Perform authorized vulnerability assessments in lab environments.

- Explore cloud security, Zero Trust, and AI-assisted security.

- Complete a cybersecurity capstone and document the investigation process.

## Daily Workflow

  

For each challenge, I will:

  

1. Learn the concept using the recommended resources.

2. Complete the assigned activity or an authorized hands-on lab.

3. Document the methodology, commands, observations, and results.

4. Record key takeaways, questions, and areas for improvement.

5. Update the progress tracker and commit the notes to GitHub.

  

## Knowledge Base

  

My notes are written in Markdown, organized for use with **Obsidian**, and version-controlled with **Git and GitHub**.

  

The repository may include:

  

- Daily learning notes

- Lab documentation and command references

- Security investigation findings

- Detection queries and log-analysis examples

- Useful tools, links, and study resources

- A final cybersecurity capstone report

## Responsible Security Practice

  

All scanning, testing, and exploitation activities are restricted to systems I own or have explicit authorization to assess. Sensitive credentials, personal information, and confidential infrastructure details will not be included in this repository.
