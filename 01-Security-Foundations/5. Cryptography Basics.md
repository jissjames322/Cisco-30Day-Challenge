### Decrypt Mary's FTP Account information

- copy the contents of the txt file

- Open Your Lab VM

Use the echo command to pipe the contents of your clipboard to the Open SSL Command


```bash
echo 'content' | openssl aes-256-cbc -pbkdf2 -a -d
```

- **aes-256-cbc**  : Tells open SSLto use the advanced encryption system with a 256 bit key length and cipher block chain.

- **pdkdf2** : Enables password-based key derivation function two, which applies a hash-based message authentication code or HMAC , to the password , along with a salt.

- **a** : tells open SSL to encode the encrypted message using a different encoding method of **base64**

- **d** : tells the application to decrypt the data.
