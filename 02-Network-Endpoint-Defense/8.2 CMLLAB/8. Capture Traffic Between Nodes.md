## Scenario

Cisco Modeling Labs is a great tool for exploring network technologies. **Whenever you dive into network operations, you may have to capture and analyze traffic exchanged between the nodes.** You will use the **packet capture and analysis feature to inspect ICMP and Spanning Tree Protocol (STP) packets on a link.**


## Task 1: Capture Traffic Using CML User Interface

In this task, you will capture all traffic that goes through a link, without any fine-tuning.

1. Log in to the Cisco Modeling Labs WebUI using the Chrome browser.
2. Make sure that your basic topology is loaded. Start the lab if needed.
3. Right-click PC1 and open its console. Log in with the username **cisco** and password **cisco**. Verify the PC1 addressing using the `ip addr` command.
4. From PC1, ping the router (10.0.1.254) and keep the ping running.
5. Right-click the link between Switch1 and the Router. Choose **Packet Capture**.
6. Click **Start**.

You can currently only have one packet capture per link. When you want to start a new capture, you can save the previous results by downloading the PCAP file to your computer.

7. After a while, you should see the captured packet counter increasing. Click **STOP**.
8. Choose one of the captured ICMP packets. The lower pane will allow you to analyze the packet. Expand the headers and inspect the available information.

**When you download the captured packets to your local machine as a PCAP file, you can examine them using a packet analysis tool, such as Wireshark**. The **PCAP** is a widely used file format that was developed in **parallel to the tcpdump and libpcap libraries.** PCAP files are easily read by various tools and software programs.

## Customize Traffic Capture

You will selectively capture STP traffic and fine-tune the capture behavior. The following settings allow you to control the capture parameters:

- **Max Packets** is the number of packets to capture. Capture will continue on the link until this number of packets have been captured.
- **Max Time** is the length of time, in seconds, to capture packets. Capture will continue on the link until this many seconds have elapsed.
- A **Berkeley Packet Filter (BPF)** can be applied to restrict which packets are captured. Cisco Modeling Labs will only capture the packets that match this filter. If you set both the max packets and a BPF, only the packets that match this filter will count toward the max packets limit.
- BPF templates include a list of several predefined templates to get you started with customizing the BPF setting.

9. Click **Settings**.
10. Set the maximum capture time to 200 seconds and choose a filter to capture only Spanning Tree packets. Click **Apply**.
