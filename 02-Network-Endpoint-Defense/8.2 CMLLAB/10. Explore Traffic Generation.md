
## Scenario

The TRex node type is used for running Cisco's TRex traffic generator within a Cisco Modeling Labs lab. It is a powerful, open-source generator that offers capabilities provided by multiple commercial tools. TRex Stateless functionality includes support for multiple Layer 3 to Layer 7 traffic streams, the ability to change any packet field, and provides per stream or group statistics, latency, and jitter. The Advanced Stateful functionality includes support for emulating Layer 7 traffic with fully featured scalable TCP/UDP support. TRex can scale up to 200 Gb/sec with one server.
