

# Introduction

Lab Management Utilities are a set of software tools used to manage and control network labs. These utilities are designed to help you set up, configure, monitor, and test network equipment in a controlled lab or testing environment. This course will guide you through four activities, each designed to improve your knowledge of the Cisco Modeling Labs environment.

You will start with covering the fundamentals of importing and exporting lab topologies and progress all the way to using the power of REST API to effectively manage your lab environment.

In the four lab activities, you will perform the following:

- Import and export lab topologies.
    
- Use the Breakout Tool to access lab topologies.
    
- Manage labs through the REST API.
    
- Use the cmlutils library for lab management.

## Import and Export Lab Topologies

At some point, you will probably want to share your labs with others or do work in a lab that is already built. Fortunately, it is easy to export and import lab topologies and their configurations into Cisco Modeling Labs.


## Task 1: Importing Lab Topologies


While you will often create a lab topology from a "blank canvas," sometimes you may want to work on a lab that someone else created. Perhaps you are studying for Cisco CCNA, and you want to explore **spanning-tree root** bridge election in a hands-on lab environment. Instead of creating an interesting topology from scratch, you can import an existing lab topology to Cisco Modeling Labs.

To import a lab into Cisco Modeling Labs, you must have a YAML file that represents the lab. In this case, you already have the lab file saved on your local machine.

1. Open the file explorer on your Student VM to find a routing vlan topology file that was provided for you in the **/home/Downloads/Labs** directory.
2. Now try to import the provided lab file. Log in to the Cisco Modeling Labs WebUI using the Chrome browser.
3. In the upper-right corner of the dashboard is a blue button for **IMPORT**. Click the **IMPORT** button to open the **Import Lab** page.
4. From this page, you can access the lab topology files saved on your local machine to import them. Click the **paperclip** icon or the **File(s) to import** textbox to choose the lab file.
