
# Explore Cisco Modeling Labs Basics


Cisco Modeling Labs is a powerful networking tool that lets you quickly and easily create and run virtual networks that can often replace real-life physical lab environments, which are more expensive and time-consuming to set up and run. **Using Cisco Modeling Labs, you can build labs to learn and explore different network protocols and test configuration changes, without the need to purchase and install any physical gear.**

With Cisco Modeling Labs, you can add the devices that you want to use, add links between the interfaces, and start the lab using only a simple WebUI that you access with your browser.


### Step 1

Access the Cisco Modeling Labs WebUI using the Chrome browser to explore an example lab simulation.

### Step 2


Log in using the credentials, username &  password

When you are logged in, you will be presented with the Dashboard page, which provides access to all existing labs. In this case, there already is a running lab simulation named Example Lab.

### Step 3 

Open the **Example Lab** simulation by clicking it and explore the topology.

In lab simulations, you can use multiple Cisco and third-party devices that behave just like they would in a real-life network.


The Cisco Modeling Labs license provides you with various Cisco devices that run the same network operating system that is running on your physical gear, but is designed to work on virtual machines:

- IOL / IOL-Layer2 (IOS on Linux)
    
- Catalyst 9800-CL
    
- IOS XR 9000v
    
- NX-OS 9000v
    
- FTDv/FMCv
    
- CAT 8000v
    
- IOSv and IOSvL2

Besides the Cisco images, Cisco Modeling Labs also provides you with open-source virtual machine images that can be used for host devices in your lab topology. Some of the available device types are also meant to be used as different networking tools, such as traffic generators:


- Server (Tiny Core Linux)
    
- Alpine Linux (GUI based and CLI based)
    
- Ubuntu
    
- Trex

## Note

The Unmanaged Switch and External Connector nodes do not count toward the total licensed node limit.

The images provided with the Cisco Modeling Labs license are sometimes referred to as "reference platforms" and can be added to Cisco Modeling Labs during the installation process.

Besides the reference platform images, Cisco Modeling Labs also allow you to add other Cisco operating systems and third-party VM images.

### Step 4

Observe all the available images by clicking the **TOOLS** button in the upper-right corner and choosing **Node and Image Definitions**.


Using different Cisco and non-Cisco devices, you can quickly build useful hands-on lab environments. Once you start the simulation, you can interact with the devices just like you would in a physical lab—by accessing the CLI or the GUI directly from Cisco Modeling Labs.
